### [AMD EPYC Zen 6 PML Support, ARM64 On s390 Merged For Linux 7.4 KVM](https://www.phoronix.com/news/Linux-7.4-KVM)

*Michael Larabel｜phoronix*

Linux 7.4 合并窗口中合入了多项 KVM（Kernel-based Virtual Machine）改进，包括 AMD EPYC Zen 6 的 PML（Page Modification Logging）支持，以及在 s390 上运行 ARM64 虚拟机的能力。这些特性面向不同服务器处理器平台带来了新的虚拟化功能。

> **学习价值**：展示了 KVM 虚拟化子系统的最新硬件特性支持，对学习虚拟化架构和脏页跟踪机制（PML）很有价值。

### [Linux's Modern NTFS Driver Now Supports Alternate Data Streams (ADS)](https://www.phoronix.com/news/NTFS-Linux-7.4-Improvements)

*Michael Larabel｜phoronix*

Linux 7.1 合入的新版 NTFS 内核驱动持续演进，Linux 7.4 将带来对 Alternate Data Streams (ADS) 的支持等新特性。这进一步增强了 Linux 对 Microsoft NTFS 文件系统的原生支持能力。

> **学习价值**：跟踪 ntfs3 驱动的功能演进有助于了解现代内核文件系统驱动的开发节奏与 Windows 兼容性设计。

### [Linux 7.4 Expands Sensor Monitoring For More ASUS & MSI Motherboards, New Minisforum Driver](https://www.phoronix.com/news/Linux-7.4-HWMON)

*Michael Larabel｜phoronix*

Linux 7.4 的 HWMON 子系统扩展了对更多 MSI 和 ASUS 主板的传感器监控支持，并新增了 Minisforum 驱动。这是又一个 HWMON 子系统的繁忙开发周期，持续扩大硬件监控覆盖范围。
