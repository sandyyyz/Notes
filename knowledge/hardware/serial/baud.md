# baud

## 1. divisor的含义

`divisor`是写入8250兼容UART（PC兼容串口）**除数锁存寄存器（Divisor Latch Registers，DLL/DLM）**的分频值。UART内部有一个固定频率的基准时钟，通过该分频值分频后产生实际的波特率时钟。

## 2. 三者的数学关系

8250 UART的波特率产生规则：

```
波特率时钟 = 基准时钟 / (divisor × 16)
```

其中：
- **16**：UART对每位采样16次（16x过采样），这是8250的固定设计；
- **基准时钟**：PC兼容串口的标准基准频率为 **1,843,200 Hz**（1.8432 MHz）。

由此推导：

```
baud = 1843200 / (divisor × 16) = 115200 / divisor
```

反解即得代码中的公式：

```c
divisor = 115200 / baud;
```

所以代码中的**115200并不是一个波特率，而是 1,843,200 / 16 的商**，即“分频值为1时对应的波特率”，是硬件常数换算的结果。

## 3. 举例验证

| 目标baud | divisor = 115200/baud | 说明 |
|---|---|---|
| 115200 | 1 | 分频值1，即最大波特率 |
| 57600 | 2 | |
| 38400 | 3 | |
| 19200 | 6 | |
| 9600 | 12 | 传统默认值 |
| 9600（实际） | 12 | 1843200/(12×16) = 9600，精确 |

注意：若baud不能整除115200（如baud=14400，divisor=8），则实际波特率与目标存在偏差；8250允许一定容差（约±3%以内可正常通信）。
