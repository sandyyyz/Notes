# `__attribute__`

是 GCC/Clang 的扩展语法：

```c
__attribute__((属性名))
```

它用于给函数、变量、类型、结构体成员等附加编译器属性，向编译器说明特殊的对齐、布局、调用约定、优化或检查要求。属性本身通常不是运行时执行的代码，而是在编译阶段影响诊断、目标代码生成或数据布局。

常见属性：

| 属性                       | 主要作用对象      | 含义                             | 常见使用场景                |
| ------------------------ | ----------- | ------------------------------ | --------------------- |
| packed                   | 结构体、联合体、字段  | 尽量取消成员之间的填充字节，使数据紧凑排列          | 网络协议、磁盘格式、硬件寄存器布局     |
| aligned(n)               | 变量、类型、字段、函数 | 指定对象至少按照 n 字节边界对齐              | 缓存行对齐、DMA 缓冲区、SIMD 数据 |
| unused                   | 函数、变量、参数、类型 | 表示对象可能有意不被使用，抑制未使用警告           | 条件编译、调试变量、兼容接口参数      |
| used                     | 函数、变量       | 即使编译器认为对象未被引用，也要求保留            | 内核元数据、链接器收集的数据项       |
| maybe_unused            | 函数、变量、参数、类型 | 表示对象可能不被使用，与 unused 用途类似       | 跨配置构建、条件编译            |
| noreturn                 | 函数          | 表示函数不会正常返回调用者                  | panic、exit、异常终止函数     |
| returns_twice           | 函数          | 表示函数可能返回两次                     | setjmp 类接口            |
| noinline                 | 函数          | 禁止编译器内联该函数                     | 调试、栈追踪、控制代码布局         |
| always_inline           | 函数          | 要求编译器尽可能强制内联                   | 高频短函数、内核性能关键路径        |
| flatten                  | 函数          | 尽可能内联该函数调用的其他函数                | 强化特定调用链的内联优化          |
| cold                     | 函数          | 表示函数很少执行                       | 错误处理、异常路径、低频分支        |
| hot                      | 函数          | 表示函数执行频率很高                     | 高频数据路径、性能关键函数         |
| pure                     | 函数          | 函数无可观察副作用，但返回值可能依赖全局内存         | 查询函数、只读计算函数           |
| const                    | 函数          | 函数无副作用，返回值只依赖显式参数              | 纯数学计算、确定性转换           |
| malloc                   | 函数          | 返回的指针指向新分配且通常不与已有对象别名的内存       | 内存分配器接口               |
| alloc_size(...)         | 函数          | 指明哪个参数表示返回内存块的大小               | malloc、calloc 风格封装    |
| warn_unused_result     | 函数          | 调用者忽略返回值时产生警告                  | 错误码、资源分配、状态检查         |
| format(...)              | 函数          | 按 printf、scanf 等规则检查格式字符串和参数类型 | 日志函数、格式化输出封装          |
| format_arg(n)           | 函数          | 表示返回值是由第 n 个格式字符串参数转换得到的       | 国际化、格式字符串包装函数         |
| nonnull(...)             | 函数参数        | 指定某些指针参数不得为 NULL               | 参数合法性检查、静态分析          |
| sentinel                 | 可变参数函数      | 要求可变参数列表以特定哨兵值结束               | 以 NULL 结尾的参数列表        |
| deprecated               | 函数、变量、类型    | 标记接口已经废弃，使用时产生警告               | API 迁移、旧接口兼容          |
| error("msg")             | 函数          | 如果相关调用未被优化消除，编译时直接报错           | 禁止调用的接口、配置检查          |
| warning("msg")           | 函数          | 调用相关函数时产生编译警告                  | 不推荐接口、危险操作提醒          |
| section("name")          | 函数、变量       | 将对象放入指定的目标文件节                  | 内核初始化段、只读段、驱动表        |
| weak                     | 函数、变量       | 将符号定义为弱符号，可被同名强符号覆盖            | 默认实现、平台覆盖、可选接口        |
| alias("target")          | 函数、变量       | 将当前符号定义为另一个符号的别名               | 接口兼容、弱符号、名称映射         |
| visibility("...")        | 函数、变量、类型    | 控制 ELF 符号的动态链接可见性              | 动态库导出、隐藏内部符号          |
| constructor              | 函数          | 在进入 main 之前自动调用                | 用户态程序或动态库初始化          |
| destructor               | 函数          | 在 main 返回后或库卸载时自动调用            | 用户态程序或动态库清理           |
| cleanup(function)        | 局部变量        | 变量离开作用域时自动调用指定清理函数             | 自动释放资源、作用域清理          |
| mode(mode)               | 变量、类型       | 指定数据类型对应的机器模式                  | 固定机器字宽、编译器底层类型        |
| transparent_union       | 联合体类型       | 允许联合体参数按其成员类型传递                | 系统接口兼容、参数类型适配         |
| vector_size(n)          | 变量、类型       | 定义总宽度为 n 字节的向量类型               | SIMD、向量化计算            |
| fallthrough              | switch 语句   | 表明 case 分支有意继续执行下一个 case       | 消除隐式贯穿警告              |
| optimize("...")          | 函数          | 为单个函数指定优化选项                    | 特定函数禁用或增强优化           |
| target("...")            | 函数          | 为单个函数指定目标 CPU 或指令集特性           | AVX、SSE、特定处理器优化       |
| no_instrument_function | 函数          | 禁止函数进入和退出时的插桩                  | 跟踪框架自身、底层调试函数         |
| no_sanitize(...)        | 函数、变量       | 禁止指定 Sanitizer 对对象进行检测         | 底层内存操作、特殊运行时代码        |
| retain                   | 函数、变量       | 防止链接阶段垃圾回收删除对应节                | 无显式引用但必须保留的对象         |
| randomize_layout | 结构体    | 编译时根据随机种子重新排列结构体成员顺序 | Linux 内核敏感结构体布局加固，降低基于固定成员偏移的漏洞利用成功率 |

`randomize_layout` 不是 GCC 原生通用属性，而是 Linux 内核通过 GCC RANDSTRUCT 插件或 Clang 对应能力实现的扩展属性。它用于在编译阶段随机重排结构体成员，从而增加攻击者根据固定成员偏移覆盖敏感字段的难度。
