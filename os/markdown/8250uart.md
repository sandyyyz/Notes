# 8250 uart
[uart通信协议](https://www.analog.com/cn/resources/analog-dialogue/articles/uart-a-hardware-communication-protocol.html)  

> The UART performs serial-te-parallel conversion on data
characters received from a peripheral device or a MODEM,
and parallel-to-serial conversion on data characters re
ceived from the CPU. The CPU can read the complete
status of the UART at any time during the functional opera
tion.   

8250 UART 最初指 National Semiconductor 的 8250 系列通用异步收发器，负责在 CPU 的并行字节访问与串行线路的逐位传输之间进行转换；后来形成了以 8250、16450、16550A 为代表的寄存器兼容体系，其中 16550 在 8250/16450 的基础上增加了收发 FIFO。Linux 中的“8250 UART”通常不是单指原始 8250 芯片，而是泛指采用这套寄存器模型的 UART 控制器，包括物理芯片、SoC 内置 UART、PCI 串口以及虚拟机模拟串口。Linux 的 drivers/tty/serial/8250/ 就是面向这类兼容设备的通用驱动框架

### Line Control Register (LCR)

> The line control register allows the specification of the format of the asynchronous data communication used. A bit in
the register also allows access to the Divisor Latches, which define the baud rate. Reading from the register is allowed
to check the current settings of the communication.

###  Interrupt Enable Register (IER)

> This register allows enabling and disabling interrupt generation by the UART.

### FIFO Control Register (FCR)

> The FCR allows selection of the FIFO trigger level (the number of bytes in FIFO required to enable the Received Data
Available interrupt). In addition, the FIFOs can be cleared using this register.

### Modem Control Register(MCR)

> The modem control register allows transferring control signals to a modem connected to the UART.

### Divisor Latches

> The divisor latches can be accessed by setting the 7th bit of LCR to ‘1’. You should restore this bit to ‘0’ after setting
the divisor latches in order to restore access to the other registers that occupy the same addresses.  
>  The 2 bytes form one
16-bit register,  
 > The value set should be equal to (system clock speed) /
(16 x desired baud rate).

### Line Status Register

This 8-bit register provides status information to the CPU
concerning the data transfer.  
Bit 5 indicates that the UART is ready to
accept a new character for transmission.
